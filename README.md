# EventForce-ManagementSystem

Salesforce based Event Planning System for Client, Vendor, Venue & Event Coordinator Management.

## Demo Video
https://drive.google.com/file/d/1gQDD8O8wbUADJIgxO2jjkD1lir0q-Xjh/view?usp=vids_web

## Features
- Client Onboarding
- Vendor Management
- Venue Booking
- Event Execution & Feedback
- Cancellation Approval Process
- Reminder Automation using Flows

## Objects Created
- Client Object
- Vendor Object
- Venue Object
- Event Coordinator Object
